# Sales Data Analysis Project

A beginner-friendly Python project that analyzes sales data using **Pandas** and visualizes the results with **Matplotlib**.

## Project Overview

This project analyzes a sample sales dataset to understand product performance and revenue across different regions.

## Analysis Performed

- Calculated total revenue.
- Summarized units sold for each product.
- Identified the best-selling product by quantity.
- Calculated revenue generated by each region.
- Created charts to visualize the results.

## Tools Used

- Python
- Pandas
- Matplotlib

## Key Findings

- **Total revenue:** ₦5,790,000
- **Best-selling product:** Mouse
- **Units of the best-selling product sold:** 23
- **Highest-revenue region:** Lagos (₦2,898,000)

## How to Run the Project

1. Make sure Python is installed.
2. Install the required libraries:

   ```bash
   python -m pip install pandas matplotlib
   ```

3. Keep `sales_analysis.py` and `sales_data.csv` in the same project folder.
4. Open a terminal in that folder and run:

   ```bash
   python sales_analysis.py
   ```

The charts are saved in the `charts` folder.
